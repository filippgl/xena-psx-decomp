Xena: Warrior Princess — нативный порт для ПК (Windows)
=======================================================

Это перекомпилированный в нативный x86-64 код оригинальной игры для PlayStation
(SLUS-00977). Эмулятора процессора нет: код игры статически переведён в C,
а железо PS1 (видеочип, GTE, CD, звук, MDEC, геймпад) заменено слоем совместимости.

Запуск
------
Положите папку рядом с образом диска "Xena Warrior Princess.bin" (или
перетащите .bin/.cue на xena.exe) и запустите xena.exe.

  xena.exe [--scale N] [путь\к\образу.bin]

Управление
----------
  Стрелки ............ крестовина        Enter .......... Start
  Z / Пробел ......... крест (X)        Backspace ...... Select
  X .................. круг             Q / W .......... L1 / R1
  A .................. квадрат          E / R .......... L2 / R2
  S .................. треугольник
  Tab (удерживать) ... ускорение        F11 / Alt+Enter  полный экран
  Esc ................ выход

Геймпады (XInput и др.) поддерживаются через SDL автоматически.

Сохранения
----------
Карта памяти хранится в папке memcard\bu00 рядом с xena.exe (обычные файлы).
