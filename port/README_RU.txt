Xena: Warrior Princess — нативный порт для ПК (Windows)
=======================================================

Это перекомпилированный в нативный x86-64 код оригинальной игры для PlayStation
(SLUS-00977). Эмулятора процессора нет: код игры статически переведён в C,
а железо PS1 (видеочип, GTE, CD, звук, MDEC, геймпад) заменено слоем совместимости.

Запуск
------
Положите папку рядом с образом диска "Xena Warrior Princess.bin" (или
перетащите .bin/.cue на xena.exe) и запустите xena.exe.

Настройки
---------
F1 (или Back+Start / кнопка Guide на геймпаде) — меню настроек прямо в игре:
разрешение рендера (до 8x), соотношение сторон 4:3 / 16:9 / 21:9, сглаживание,
фильтрация текстур, коррекция перспективы, полный экран, вибрация, мышь.
Всё сохраняется в xena.ini рядом с программой; там же переназначаются клавиши,
кнопки мыши и геймпада.

Горячие клавиши: F11 или Alt+Enter — полный экран, F5 — соотношение сторон,
F6 — разрешение рендера.

Управление по умолчанию
-----------------------
  W A S D / стрелки .. движение          Enter / Esc ...... Start (пауза)
  Пробел / K ......... крест (X)         Backspace / Tab .. Select
  J .................. квадрат           Q / E ............ L1 / R1
  L .................. круг              Z / C ............ L2 / R2
  I .................. треугольник       ` (тильда) ....... ускорение (удерживать)

Мышь: щёлкните по окну, чтобы захватить мышь (Alt — отпустить).
  движение влево-вправо — поворот, левая кнопка — квадрат, правая — круг,
  средняя — треугольник, колесо — L1 / R1, боковые кнопки — L2 / R2.

Геймпады Xbox, PlayStation 4/5, Switch Pro и др. работают сразу (через SDL):
  A/B/X/Y = крест/круг/квадрат/треугольник по расположению, левый стик и
  крестовина — движение, правый стик влево-вправо — поворот, вибрация
  передаётся из игры (включите «Вибрация» в опциях игры).

Выход — закрыть окно.

Сохранения
----------
Карта памяти хранится в папке memcard\bu00 рядом с xena.exe (обычные файлы).

Производительность
------------------
Высокие разрешения и SSAA считаются на процессоре во всех потоках. Если кадров
меньше 60 (видно в заголовке окна), уменьшите «Разрешение рендера» или выключите
сглаживание.
