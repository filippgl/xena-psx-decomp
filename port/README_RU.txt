Xena: Warrior Princess — нативный порт для ПК (Windows)
=======================================================

Это перекомпилированный в нативный x86-64 код оригинальной игры для PlayStation
(SLUS-00977). Эмулятора процессора нет: код игры статически переведён в C,
а железо PS1 (видеочип, GTE, CD, звук, MDEC, геймпад) заменено слоем совместимости.

Запуск
------
Положите папку рядом с образом диска "Xena Warrior Princess.bin" (или
перетащите .bin/.cue на xena.exe) и запустите xena.exe.

Графика
-------
По умолчанию рисует видеокарта (OpenGL 3.3); если её нет, включается рендер
на процессоре. В меню настроек (F1):
  - разрешение рендера до 8x, соотношение сторон 4:3 / 16:9 / 21:9;
  - сглаживание SSAA, фильтрация текстур, коррекция перспективы;
  - «Перерисованные текстуры» — текстуры высокого разрешения из папки textures
    (нарисованы нейросетью по оригиналам; работают только на видеокарте).

Всё сохраняется в xena.ini рядом с программой; там же переназначаются клавиши,
кнопки мыши и геймпада.

Горячие клавиши: F1 — настройки, F11 или Alt+Enter — полный экран,
F5 — соотношение сторон, F6 — разрешение рендера.

Управление по умолчанию
-----------------------
  W A S D / стрелки .. движение          Enter / Esc ...... Start (пауза)
  Пробел / K ......... крест (X)         Backspace / Tab .. Select
  J .................. квадрат           Q / E ............ L1 / R1
  L .................. круг              Z / C ............ L2 / R2
  I .................. треугольник       ` (тильда) ....... ускорение (удерживать)

Движение — относительно камеры: Зена бежит туда, куда нажато на экране
(вправо — вправо, назад — к камере), левый стик работает с любым углом.
Атаки, прыжки и лазание — как в оригинале. Оригинальное «танковое» управление
(вперёд — бег, влево/вправо — поворот) включается в F1 → «Управление».

Мышь: левая кнопка — квадрат, правая — круг, средняя — треугольник,
колесо — L1 / R1, боковые кнопки — L2 / R2. При классическом управлении можно
включить поворот мышью (F1 → «Поворот мышью»; щелчок по окну захватывает мышь,
Alt — отпускает).

Геймпады Xbox, PlayStation 4/5, Switch Pro и др. работают сразу (через SDL).
Меню настроек на геймпаде: Back+Start или кнопка Guide. Вибрация передаётся
из игры (включите «Вибрация» в опциях игры).

Выход — закрыть окно.

Свои перерисованные текстуры
----------------------------
Готовый набор покрывает меню и первый уровень. Для остальных уровней:
1. Включите в настройках «Сбор текстур» и пройдите нужные места — текстуры
   сохранятся в папку texture_dump.
2. Перерисуйте их (нужны Python с Pillow/numpy и Codex CLI):
     python tools\texdump2png.py texture_dump
     python tools\codex_textures.py texture_dump\manifest.txt texture_dump textures
   (скрипты — в репозитории порта; уже готовые текстуры пропускаются)
3. Допишите строки texture_dump\manifest.txt в textures\manifest.txt.

Сохранения
----------
Карта памяти хранится в папке memcard\bu00 рядом с xena.exe (обычные файлы).
