# Xena: прототип перемещения и боя на первой локации

Запуск из папки игры: **Play-Unity-Prototype.cmd**. Unity Hub и Editor не нужны.
Исполняемый файл: `decomp/build/unity-movement/XenaMovementPrototype.exe`.
Окно запускается в 1280×720. Из архива запускайте EXE, сохранив рядом все папки
данных и библиотеки. Для редактора есть **Open-Xena-Movement.cmd**; сцена —
`Assets/Scenes/Level01MovementPrototype.unity`. При существующей сцене инструмент
открывает её, сохраняя пользовательские изменения.

| Действие | Клавиатура/мышь | Геймпад |
| --- | --- | --- |
| Движение относительно камеры | WASD | Левый стик |
| Обзор | Мышь | Правый стик |
| Бег | Shift удерживать | L3 удерживать |
| Прыжок | Space | Нижняя кнопка A/× |
| Удар мечом | ЛКМ, отдельные нажатия | Левая лицевая X/□ |
| Удар ногой | F, отдельные нажатия | Верхняя лицевая Y/△ |
| Блок | ПКМ удерживать | LB/L1 удерживать |
| Пауза и настройки камеры | Esc | Start |
| Возврат на старт | R | Select/View |

В паузе доступны чувствительность мыши и инверсия Y. Настройки пока действуют
только в текущем запуске; переназначение кнопок в Windows-меню ещё не добавлено.
Там же можно включить атаки учебного манекена: вблизи он наносит удар раз в две
секунды и перед этим подсвечивается жёлтым. Блок защищает спереди. Манекен стоит
примерно в трёх метрах справа от старта; попадание подсвечивает его красным.
R восстанавливает здоровье игрока и манекена и выключает его атаки.
Профиль действий Input System находится в `Input/XenaPrototype.inputactions` пакета.
Используется [Input System 1.20.1, выпущенный для Unity 6000.3](https://docs.unity.com/en-us/engine/6000.3/manual/packages-list/packages-all/pack-safe/com-unity-inputsystem).

Сцена использует оригинальную Зену и 4× текстуры, её исходные клипы движения,
первую локацию с LGT и исходную точку Зены из PLRS. Пол: 2290 треугольников;
для стен подготовлены 119 треугольников оригинального CLS. Все 1071 координатное
значение CLS сверены с ранее проверенным снимком памяти. Для капсулы создана
двусторонняя копия этих треугольников; исходные ресурсы не изменяются.

Перемещение капсулы и камера — реализация прототипа, а не восстановленная
физика PS1. Запрос высоты использует проверенный целочисленный алгоритм оригинала.
Шаг прототипа явно равен 1/60 секунды; это не измерение частоты исходной логики.
Скорости 2.5/5.5, сила прыжка 6 и гравитация 20 — временные настраиваемые значения
при предполагаемом масштабе 400 единиц PS1 на метр. Клипы sampled без root motion.
Прыжок использует оригинальный клип `0x2F` (44 кадра). Его позы сверены с
архивными снимками памяти нативного порта: отрыв — кадр 6, вершина — 17,
касание земли — 29, номера с нуля. Подъём и падение задают фазу анимации;
после посадки кадры 29–43 проигрываются один раз. Движение и новый прыжок
прерывают завершение посадки. Подготовительная часть пропущена ради немедленного
отклика Space; физика и длительность полёта остаются настройками прототипа.
При сходе с края пока используется та же нисходящая фаза, без отдельного клипа падения.
Состояние/клип `0x35` в исследованных снимках — прыжок с перемещением,
а не отдельное приземление. Отчёт: `build/animation-audit/jump-verification.json`;
повторить: `node tools/inspect_xena_jump.mjs` (нужны исходные локальные RAM-снимки).
Подключён учебный бой: меч `51 → 52 → 3A`, нога `61 → 62 → 5A`, блок `80`.
Следующий удар можно нажать заранее; удержание кнопки не повторяет атаки.
Во время удара и блока перемещение приостановлено. Смешанные оригинальные
комбинации, приёмы с блоком, атаки с разбега и в воздухе ещё не перенесены.
Одновременные ЛКМ+F пока выбирают меч; ПКМ подавляет новые атаки.
Чакрам, исходные NPC/AI, события уровня и сохранения не подключены.

Дальность, контактные кадры и урон манекена — временные правила учебного режима:
меч 20, нога 15, атака манекена 10, здоровье 100. Это не восстановленные хитбоксы
и баланс PS1. При нулевом здоровье игрока смерть/перезагрузка ещё не реализованы.
Подробности исходных цепочек и границ проверки: `xena-combat-audit.md`.

Движение теперь проходит через исходные слоты `0x14` (5 кадров старта),
`0x15` (25 кадров повторяющегося цикла) и `0x17` (7 кадров остановки), затем
возвращается в стойку `0x00`. Переключение Shift сохраняет фазу цикла.
Новая команда движения прерывает остановку. Ходьба использует тот же цикл
с меньшей частотой: отдельный оригинальный клип ходьбы пока не установлен.
Сверка с нативным портом: `node tools/inspect_xena_locomotion.mjs`;
подробности — `xena-locomotion-audit.md`.

Windows x64 сборка и настоящий запуск проверены на RTX 4070 SUPER. 22 проверки
используют виртуальные Keyboard/Mouse/Gamepad устройства Input System внутри
процесса игры, не отправляя клавиши другим приложениям. Проверены ходьба, бег,
диагональ, камера мыши/правого стика, прыжок/приземление, пауза, сброс, препятствия
капсулы и камеры, а также одинаковое перемещение при ограничениях 30 и 120 FPS.
Это проверки начального участка и временных тестовых препятствий; полный уровень
от начала до конца не проходился. Логи и отчёты — `build/unity-import/movement-*`.
Дополнительно проверены оригинальные позы в воздухе, однократное завершение посадки,
прерывание посадки движением и сброс позы. Снимки полёта/посадки:
`movement-jump-air.png`, `movement-jump-land.png` в той же папке.
Отдельный `check_combat_player.mjs` проверяет 24 сценария учебного боя: реальные
клики/клавиши/геймпад через виртуальные устройства, обе тройные серии, истечение
буфера, защиту спереди/удар сзади, стену, дальность, паузу и сброс. Отчёт —
`build/unity-import/combat-player-verification.json`; снимки — `combat-*.png`.

Повторить из `decomp/` при закрытом соответствующем Editor:

```powershell
node tools/prepare_movement_prototype.mjs --verification
node tools/prepare_unity_project.mjs
node tools/run_unity_import.mjs --editor "../Unity63/Editor/Unity.exe" --project unity/XenaLightingVerification --movement
node tools/check_movement_player.mjs
node tools/check_combat_player.mjs
```

Для создания сцены в основном проекте без повторной сборки: тот же wrapper с
`--movement-scene` и без `--project`. Полный импорт ресурсов и рендеринг проверяются
отдельными командами из `unity-import.md`. Новые сцены не заменяют ранее созданные
просмотры модели и локации; нативный PC-порт также остаётся отдельным.
