# Приёмы с разбега и из блока

Контролируемые сценарии:

```powershell
node tools/capture_action_reference.mjs running
node tools/verify_action_reference.mjs running
node tools/capture_action_reference.mjs guardattacks
node tools/verify_action_reference.mjs guardattacks
```

Проверено 243 + 233 RAM-снимка и 46 656 + 44 736 компонентов поз существующего
нативного порта. Нативный EXE не изменялся: `build/port/xena-console.exe`,
время изменения `2026-10-22T18:11:35.259Z`. Корень мирового перемещения исключён
из проверки локальной позы; его позиции записаны в отчётах как наблюдения.

| Ввод оригинала | Наблюдаемые слоты | Длительность |
| --- | --- | --- |
| UP+L1, затем Square | `1A → 3C → 00` | Перекат `3C`: 41 кадр |
| UP+L1, затем Cross | `1A → 3E → 00` | Атака с разбега `3E`: 40 кадров |
| UP+L1, затем Triangle | `1A → 31 → 00` | Прыжок с переворотом `31`: 47 кадров |
| Circle, затем Square | `80 → 5C → 00` | Круговой удар ногой `5C`: 39 кадров |
| Circle, затем Cross | `80 → 46 → 00` | Удар из блока `46`: 28 кадров |

Для `31` исходная таблица по `0x800C1474` содержит `[6,20,34,85]`.
Наблюдаемый верх полёта находится около кадров 18/19, возвращение на землю —
около 33. Прототип использует кадры 6 → 19 → 32 в воздухе и 33–46 при посадке,
сохраняя собственную баллистику прыжка, как для ранее добавленного `2F`.
Это привязка исходных поз к современному мотору, а не совпадение траектории PS1.

Дополнительно зафиксирована серия Cross+Square `4C → 4D → 4E`; `4D` повторяется
перед выходом. Этот сценарий пока служит материалом аудита: приём ещё не подключён,
поскольку условия продолжения и завершения повтора требуют отдельной проверки.

Артефакты: `build/action-reference-running/verification.json` и
`build/action-reference-guardattacks/verification.json`.

Управление прототипом: Shift+движение+F — перекат, Shift+движение+ЛКМ — атака
с разбега, Shift+движение+Space — прыжок с переворотом; ПКМ+F — круговой удар
ногой, ПКМ+ЛКМ — удар из блока. На геймпаде используются те же действия:
бег L3, движение левым стиком, нога Y/△, меч X/□, прыжок A/×, блок LB/L1.

Перемещение переката/атаки и урон пока временные: 8 м за перекат, 5 м за атаку,
с ограничением капсулой и геометрией. Перекат не наносит учебного урона.
Круговой удар проверяет манекены со всех сторон, удар `46` — спереди;
обе атаки наносят временный урон 15, по одному контакту на цель. Исходные активные
кадры попаданий, радиусы, неуязвимость и точное перемещение ещё не перенесены.
