# Круговая серия, сальто назад и направленные атаки

`capture_action_reference.mjs spin` и `verify_action_reference.mjs spin`
проверили 253 снимка и 48 576 компонентов поз. Последовательность —
`4C` (18 кадров), `4D` (7 кадров, повтор), `4E` (31 кадр).
Короткое совместное нажатие и удержание Cross+Square дали по два цикла `4D`;
повторные нажатия в третьем интервале — четыре. Само удержание не продлевает приём.
Источник `8003A434..8003A47C` принимает новый Square при `actor+E4 == 4`,
меняет это поле на 5 и уменьшает счётчик `gp+4AB0`; `8003A740` задаёт бюджет 6.
В снимках флаг 4/5 относится к паре семикадровых циклов: принимается не больше
одного продления на пару. В Unity воспроизведены эти пары и бюджет; активные кадры
урона оригинала ещё не восстановлены. Учебный контакт выполняется только на `4D`,
по одному на цель за семикадровый цикл, с временным уроном меча 20.

ЛКМ+F запускает серию. После запуска можно удерживать ЛКМ и повторно нажимать F.
Чтобы не требовать попадания обеими кнопками в один физический такт, второй край
кнопки может заменить первые два ещё не контактных кадра обычного `51/61`.
Это допуск современного ввода, а не доказанное временное окно PS1. Уже принятая
обычная комбинация не заменяется. Чакрам и блок сохраняют свой приоритет.

`capture_action_reference.mjs directional-classic` с `--opt modern_controls=0`
и `verify_action_reference.mjs directional-classic` проверили 228 снимков,
43 776 компонентов поз. Down+Triangle даёт `35` на 32 кадра; корень перемещается
назад, направление взгляда не меняется. Таблица по `800C146C`: `[4,13,22,40]`.
В прототипе направление назад считается относительно персонажа до поворота:
позы 4 → 12 → 20 привязаны к баллистике, посадка — 21–31 один раз.
Скорость/дальность и баллистика остаются настройками прототипа.

Включённое современное управление нативного порта заменяло этот ввод обычным `2F`;
оба набора снимков сохранены отдельно. Изменение режима задаётся аргументом одного
процесса; пользовательский INI и EXE не изменяются.

Down+Cross/Square в классическом сценарии дали обычные `51/61` с изменением
направления корня. Отдельный «180-градусный» клип этим не найден. Современный
контроллер теперь разворачивается к запросу назад перед запуском обычной атаки,
вместо фиксации прежнего взгляда. Это проверяется как поведение PC-управления,
без заявления о совпадении танковой математики поворота PS1.

Bicycle kick пока не перенесён. Одновременные и разнесённые Jump+Kick без цели
дали обычные прыжки/удары. В исходной таблице `800C76FC`, строки 12/13, есть запрос
`5F` для сочетаний Jump/Kick; ветка `8003A794..8003A844` требует объект с флагом
класса `0x10`, допустимым состоянием, расстоянием меньше 1000 и углом меньше 700.
Тесты `bicycle-target`/`bicycle-target-stagger` временно переместили существующий
объект `80151270` через `--poke` в гостевой RAM; это отмечено в capture.json.
Они также не подтвердили запуск `5F` — возникли `2F/42/61`. Приём и реакцию цели
нельзя объявлять восстановленными только по короткому клипу. Нужен отдельный
аудит допустимой цели и распознавателя сочетаний. Исходные ресурсы не менялись.
