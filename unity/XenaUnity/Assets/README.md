# Xena: asset import proof

Run `node tools/export_xena_unity.mjs` from the decomp repository root first.
Open this project with Unity 6.3 LTS. Its local package imports `.xenamodel`.
Then choose **Tools > Xena > Create Asset Preview Scene**, and enter Play mode.

The project is an asset and animation preview, not a playable game level.
Generated assets, scenes and settings are excluded from source control.
See `../../../docs/unity-import.md` for validation and batch commands.
